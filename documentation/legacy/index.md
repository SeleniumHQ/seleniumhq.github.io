# Legacy

> Documentation related to the legacy components of Selenium. Meant to be kept purely for historical reasons  and not as a incentive to use deprecated components.

URL: https://www.selenium.dev/documentation/legacy/
Site index: https://www.selenium.dev/llms.txt

---

Section pages:

- [Selenium RC (Selenium 1)](https://www.selenium.dev/documentation/legacy/selenium_1/index.md): The original version of Selenium
- [Selenium 2](https://www.selenium.dev/documentation/legacy/selenium_2/index.md): Selenium 2 was a rewrite of Selenium 1 that was implemented with WebDriver code.
- [Selenium 3](https://www.selenium.dev/documentation/legacy/selenium_3/index.md): Selenium 3 was the implementation of WebDriver without the Selenium RC Code. It has since been replaced with Selenium 4, which implements the W3C WebDriver specification.
- [Legacy Selenium IDE](https://www.selenium.dev/documentation/legacy/selenium_ide/index.md): Selenium IDE was the original Firefox extension for Record and Playback.
- [IE Driver Server](https://www.selenium.dev/documentation/legacy/ie_driver_server/index.md): The Internet Explorer Driver is a standalone server that implements the WebDriver specification.
- [JSON Wire Protocol Specification](https://www.selenium.dev/documentation/legacy/json_wire_protocol/index.md): The endpoints and payloads for the now-obsolete open source protocol that was the precursor to the [W3C specification](https://w3c.github.io/webdriver/).
- [Legacy Selenium Desired Capabilities](https://www.selenium.dev/documentation/legacy/desired_capabilities/index.md): These capabilities worked with the legacy JSON Wire Protocol
- [Legacy developer documentation](https://www.selenium.dev/documentation/legacy/developers/index.md): Information of interest to developers of Selenium
