# Selenium 3

> Selenium 3 was the implementation of WebDriver without the Selenium RC Code. It has since been replaced with Selenium 4, which implements the W3C WebDriver specification.

URL: https://www.selenium.dev/documentation/legacy/selenium_3/
Site index: https://www.selenium.dev/llms.txt

---

Section pages:

- [Grid 3](https://www.selenium.dev/documentation/legacy/selenium_3/grid_3/index.md): Selenium Grid 3 supported WebDriver without Selenium RC code. Grid 3 was completely rewritten for the new Grid 4.
- [Setting up your own Grid 3](https://www.selenium.dev/documentation/legacy/selenium_3/grid_setup/index.md): Quick start guide for setting up Grid 3.
- [Components of Grid 3](https://www.selenium.dev/documentation/legacy/selenium_3/grid_components/index.md): Description of Hub and Nodes for Grid 3.
- [Migrating WebDriverJS off the Promise Manager](https://www.selenium.dev/documentation/legacy/selenium_3/webdriverjs/index.md): How to move JavaScript tests from the WebDriverJS promise manager to async/await.
- [Selenium 3 Python Bindings](https://www.selenium.dev/documentation/legacy/selenium_3/python_bindings/index.md): Installing, using and developing the Python bindings in the Selenium 3 era.
- [Selenium 3 Ruby Bindings](https://www.selenium.dev/documentation/legacy/selenium_3/ruby_bindings/index.md): Usage examples for the Ruby bindings in the Selenium 3 era.
