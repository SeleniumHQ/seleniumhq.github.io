# Selenium 2

> Selenium 2 was a rewrite of Selenium 1 that was implemented with WebDriver code.

URL: https://www.selenium.dev/documentation/legacy/selenium_2/
Site index: https://www.selenium.dev/llms.txt

---

Section pages:

- [Migrating from RC to WebDriver](https://www.selenium.dev/documentation/legacy/selenium_2/upgrading/index.md): Information on Updating from Selenium 1 to Selenium 2.
- [Backing Selenium with WebDriver](https://www.selenium.dev/documentation/legacy/selenium_2/emulation/index.md): The Java and .NET versions of Selenium 2 provided implementations of the original Selenium API
- [Legacy Firefox Driver](https://www.selenium.dev/documentation/legacy/selenium_2/firefox_driver/index.md): The legacy Firefox Driver was developed as a browser extension by the Selenium Developers. Firefox updated their security model, so it no longer works. You now need to use geckodriver.
- [HtmlUnit Driver](https://www.selenium.dev/documentation/legacy/selenium_2/htmlunit_driver/index.md): The headless, pure Java WebDriver implementation based on HtmlUnit.
- [Using the LoadableComponent](https://www.selenium.dev/documentation/legacy/selenium_2/loadable_component/index.md): Java base class that standardizes how Page Objects load.
- [Selenium grid 2](https://www.selenium.dev/documentation/legacy/selenium_2/grid_2/index.md): Selenium Grid 2 supported WebDriver and Selenium RC. It was replaced by Grid 3 which removed RC code. Grid 3 was completely rewritten for the new Grid 4.
- [The PageFactory](https://www.selenium.dev/documentation/legacy/selenium_2/page_factory/index.md): Java support class for initializing WebElement fields in Page Objects.
- [History of Grid Platforms](https://www.selenium.dev/documentation/legacy/selenium_2/grid_platforms/index.md): Information for working with platform names in Grid 2.
- [Remote WebDriver standalone server](https://www.selenium.dev/documentation/legacy/selenium_2/remote_server/index.md): Working with the Standalone Server.
- [Remote WebDriver client](https://www.selenium.dev/documentation/legacy/selenium_2/remote_webdriver/index.md): Using the RemoteWebDriver client in Selenium 2.
- [Limitations of scaling up tests in Selenium 2](https://www.selenium.dev/documentation/legacy/selenium_2/parallel_execution/index.md): Summary of additional constraints that arise when running Selenium2 in parallel.
- [Stealing focus from Firefox in Linux](https://www.selenium.dev/documentation/legacy/selenium_2/focus_stealing/index.md): How to work with Native Events in the Legacy Firefox extension.
- [Untrusted SSL Certificates](https://www.selenium.dev/documentation/legacy/selenium_2/ssl_certs/index.md): Details on how Selenium 2 accepted untrusted SSL certificates
- [WebDriver For Mobile Browsers](https://www.selenium.dev/documentation/legacy/selenium_2/mobile/index.md): Describes how Selenium 2 supported Android and iOS before Appium was created
- [Frequently Asked Questions for Selenium 2](https://www.selenium.dev/documentation/legacy/selenium_2/faq/index.md): Items of interest for moving from Selenium 1 to Selenium 2
- [How XPath Works in WebDriver](https://www.selenium.dev/documentation/legacy/selenium_2/xpath/index.md): Differences between the XPath engines used by the Selenium 2 drivers.
- [Selenium 2.0 Team](https://www.selenium.dev/documentation/legacy/selenium_2/team/index.md): This is who you can blame for the Selenium 2 release.
