# Legacy developer documentation

> Information of interest to developers of Selenium

URL: https://www.selenium.dev/documentation/legacy/developers/
Site index: https://www.selenium.dev/llms.txt

---

Section pages:

- [Architectural Overview and Design Principles](https://www.selenium.dev/documentation/legacy/developers/architecture/index.md): The original design principles behind the WebDriver implementations.
- [Crazy Fun Build Tool](https://www.selenium.dev/documentation/legacy/developers/crazy_fun_build/index.md): The original Selenium Build Tool that grew from nothing to be extremely unwieldy, making it both crazy and "fun" to work with.
- [Browser Automation Atoms](https://www.selenium.dev/documentation/legacy/developers/atoms/index.md): Shared JavaScript building blocks used across Selenium driver implementations.
- [Buck Build Tool](https://www.selenium.dev/documentation/legacy/developers/buck/index.md): Buck is a build tool from Facebook that we were working with to replace Crazy fun. We have since replaced it with [Bazel](https://bazel.build/).
- [Adding new drivers to Selenium 2 code](https://www.selenium.dev/documentation/legacy/developers/drivers/index.md): Instructions for how to create tests for new drivers for Selenium 2.
- [Selenium's Continuous Integration Implementation](https://www.selenium.dev/documentation/legacy/developers/ci_tool/index.md): We used to have a Jenkins CI tool that executed unit tests and ran integration tests on Sauce Labs. We moved all of the tests to Travis, and now execute everything with Github Actions.
- [Google Summer of Code 2011](https://www.selenium.dev/documentation/legacy/developers/summer_of_code/index.md): Selenium encouraged users to take advantage of this program.
- [Logging in WebDriver](https://www.selenium.dev/documentation/legacy/developers/logging/index.md): The original design for log types, levels and retrieval in the JSON Wire Protocol.
- [Developer Tips](https://www.selenium.dev/documentation/legacy/developers/tips/index.md): Details on how to execute Selenium Test Suite with Crazy Fun.
- [Ruby Development with Crazy Fun](https://www.selenium.dev/documentation/legacy/developers/ruby_development/index.md): How to build and test the Ruby bindings with the Crazy Fun build.
- [Snapshot of Roadmaps for Selenium Releases](https://www.selenium.dev/documentation/legacy/developers/roadmap/index.md): The list of plans and things to accomplish before a release
