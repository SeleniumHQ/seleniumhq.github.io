Getting started

Install Selenium, write your first script, and run it.

    This page takes you from an empty project to a running Selenium script, and then shows how to run the same code with a test runner.

    You will learn

    • How to install the Selenium library for your programming language
    • How to write and run a first script that opens a browser, interacts with a page, and closes it
    • How to run the same code with a test runner

    Install

    No driver downloads

    From Selenium 4.6 onwards you no longer need to download or manage browser drivers. Selenium Manager finds the driver that matches your browser, and downloads the browser itself if none is installed.

    Add the Selenium library to your project. Check the downloads page for the latest version.

    Add the dependency to your build file. The minimum supported Java version is listed in the Selenium source.

    Or add gem 'selenium-webdriver' to your Gemfile. The minimum supported Ruby version for each release is listed on RubyGems.

    Your first script

    Every Selenium call either tells the browser to do something or asks it for information. This script uses the eight commands you will use in almost every session:

    1. Start the driver session
    2. Navigate to a page
    3. Request information about the browser
    4. Establish a waiting strategy
    5. Find elements
    6. Act on an element
    7. Request element information
    8. End the session with quit
    package dev.selenium.getting_started;

import org.openqa.selenium.By;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.WebElement;
import org.openqa.selenium.chrome.ChromeDriver;

import java.time.Duration;

public class FirstScript {
    public static void main(String[] args) {
        WebDriver driver = new ChromeDriver();

        driver.get("https://www.selenium.dev/selenium/web/web-form.html");

        driver.getTitle();

        driver.manage().timeouts().implicitlyWait(Duration.ofMillis(500));

        WebElement textBox = driver.findElement(By.name("my-text"));
        WebElement submitButton = driver.findElement(By.cssSelector("button"));

        textBox.sendKeys("Selenium");
        submitButton.click();

        WebElement message = driver.findElement(By.id("message"));
        message.getText();

        driver.quit();
    }
}

    Run it with a test runner

    Most people use Selenium to test web applications. A test runner gives you before and after hooks, assertions, and reporting, and lets you run tests in groups or in parallel. Here is the same script structured as a test, with one runner for each language:

    JUnit

    package dev.selenium.getting_started;

import static org.junit.jupiter.api.Assertions.assertEquals;

import java.time.Duration;

import org.junit.jupiter.api.AfterEach;
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.Test;
import org.openqa.selenium.By;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.WebElement;
import org.openqa.selenium.chrome.ChromeDriver;

public class UsingSeleniumTest {

	WebDriver driver;

	@BeforeEach
	public void setup() {
		driver = new ChromeDriver();
	}

	@Test
	public void eightComponents() {

		driver.manage().timeouts().implicitlyWait(Duration.ofMillis(500));
		driver.get("https://www.selenium.dev/selenium/web/web-form.html");

		String title = driver.getTitle();
		assertEquals("Web form", title);

		WebElement textBox = driver.findElement(By.name("my-text"));
		WebElement submitButton = driver.findElement(By.cssSelector("button"));

		textBox.sendKeys("Selenium");
		submitButton.click();

		WebElement message = driver.findElement(By.id("message"));
		String value = message.getText();
		assertEquals("Received!", value);

	}

	@AfterEach
	public final void teardown() {
		if (driver != null) {
			driver.quit();
		}
	}

}
