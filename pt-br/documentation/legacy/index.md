# Legado

> Nesta seção você pode encontrar toda a documentação relacionada aos componentes legados do Selenium. Isso deve ser mantido puramente por razões históricas e não como um incentivo para o uso obsoleto componentes.

URL: https://www.selenium.dev/pt-br/documentation/legacy/

Section pages:

- [Selenium RC (Selenium 1)](https://www.selenium.dev/pt-br/documentation/legacy/selenium_1/index.md): The original version of Selenium
- [Selenium 2](https://www.selenium.dev/pt-br/documentation/legacy/selenium_2/index.md): Selenium 2 was a rewrite of Selenium 1 that was implemented with WebDriver code.
- [Selenium 3](https://www.selenium.dev/pt-br/documentation/legacy/selenium_3/index.md): Selenium 3 was the implementation of WebDriver without the Selenium RC Code. It has since been replaced with Selenium 4, which implements the W3C WebDriver specification.
- [Selenium IDE Legado](https://www.selenium.dev/pt-br/documentation/legacy/selenium_ide/index.md)
- [Servidor de drivers do IE](https://www.selenium.dev/pt-br/documentation/legacy/ie_driver_server/index.md): O Internet Explorer Driver é um servidor autónomo que implementa a especificação WebDriver.
