# Support features

> 针对更高层面功能的额外支持类.

URL: https://www.selenium.dev/zh-cn/documentation/webdriver/support_features/

---

Selenium的核心库试图提供底层以及普适的功能.
每种语言的支持类都为常见交互提供特定的包装器, 
可用于简化某些行为.

---

Section pages:

- [期望状态的等待](https://www.selenium.dev/zh-cn/documentation/webdriver/support_features/expected_conditions/index.md): 本文档描述了一系列类, 这些类用于明确指定在测试中需要等待的各种条件.
- [命令监听器](https://www.selenium.dev/zh-cn/documentation/webdriver/support_features/listeners/index.md)
- [同颜色一起工作](https://www.selenium.dev/zh-cn/documentation/webdriver/support_features/colors/index.md)
- [线程守卫](https://www.selenium.dev/zh-cn/documentation/webdriver/support_features/thread_guard/index.md)
- [使用选择列表元素](https://www.selenium.dev/zh-cn/documentation/webdriver/support_features/select_lists/index.md): 与其他元素相比，选择列表具有特殊的行为.
