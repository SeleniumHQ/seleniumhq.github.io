# Grid

> 要在多台计算机上并行运行测试吗? 那么, Grid正是为你准备的.

URL: https://www.selenium.dev/zh-cn/documentation/grid/

---

Selenium Grid 允许通过将客户端发送的命令路由到远程浏览器实例来在远程机器上执行 WebDriver 脚本。 

Grid 的目标:

* 提供一种在多台机器上并行运行测试的简单方法
* 允许在不同的浏览器版本上进行测试
* 启用跨平台测试

感兴趣? 通过以下部分了解Grid的工作原理, 以及如何设置自己的.
