  Bodies use .RawContent (the page's Markdown, front matter excluded), cleaned up
  below, rather than .Plain. .Plain is the rendered page with the tags stripped,

  fenced code as the author wrote them; only the Hugo shortcodes need rewriting:

  - gh-codeblock becomes a link to the example file and line range on GitHub.
  - tab shortcodes become a bold language label.
  - ref/relref links with an absolute path become absolute selenium.dev URLs;
    page-relative ones cannot be resolved by a regex, so only their text is kept.
  - every other shortcode tag is removed, keeping the text between the tags.
*/ -}}
